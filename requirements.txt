# Known GPU compatibility issue:
# DeepChem 2.7.1 requires PyTorch 2.0.1, which only ships CUDA 11.8 kernels.
# GPUs with Blackwell (RTX 50xx) or Ada Lovelace (RTX 40xx) architecture need
# CUDA 12.x+ and PyTorch >= 2.2 (Blackwell needs >= 2.6). Because DeepChem
# pins the older PyTorch, these GPUs cannot run CUDA — models will fall back
# to CPU-only mode. This affects all PyTorch and DeepChem models (DMPNN, GRU,
# etc.) but not classical ML models (RF, SVM) which use scikit-learn on CPU.
# For GPU acceleration, either use an older GPU (Ampere / RTX 30xx or earlier)
# or wait for a DeepChem release compatible with PyTorch >= 2.6.
